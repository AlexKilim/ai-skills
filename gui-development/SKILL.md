---
name: gui-development
description: Keep graphical interfaces compact and easy to scan when creating or changing screens or controls in desktop, web, or touch applications.
---

Keep primary actions and important states visible. Put supplementary explanations in short hover tooltips for icon-only buttons and controls whose purpose is unclear. Show information needed to operate the interface directly on screen. On touch-only interfaces, use a visible label or an explicit help control where an explanation is needed.

For mutually exclusive actions on the same process, use one button when its label clearly identifies the next action. For example, change Start to Stop after startup is confirmed. Show a pending state while the command is in progress. Keep the button in the same position and preserve its hit area when the label or icon changes. Reserve enough space for the longest label so adjacent controls stay in place. Use separate buttons when the actions need to be available independently.
