# Предпочитаемые скиллы

Начальный список собран по явным запросам, правилам проекта и установленным скиллам, которые дополняют эти сценарии. Выбирайте по задаче. Если есть свидетельства, что скилл устарел, дублирует другой или хуже подходит к задаче, проверьте конкретную альтернативу и предложите изменение списка через `skill-maintenance`.

| Задача | Предпочитаемый скилл и условие применения |
|---|---|
| Код на C++ | [modern-cpp-style](https://github.com/AlexKilim/ai-skills/blob/main/modern-cpp-style/SKILL.md) для написания и ревью. |
| Правка файлов с чувствительной кодировкой или через связанный компьютер | [file-edit](https://github.com/AlexKilim/ai-skills/blob/main/file-edit/SKILL.md) для сохранения байтов и проверки записи. |
| Работа с трекером Gitea | [gitea](https://github.com/AlexKilim/ai-skills/blob/main/gitea/SKILL.md) при чтении, обновлении и публикации задач. |
| Настольный интерфейс на Qt Widgets | [qt-widgets-development](https://github.com/AlexKilim/ai-skills/blob/main/qt-widgets-development/SKILL.md) для компонентов, темы и приборных экранов. `qt-ui-design` при проектировании экранов и навигации. `qt-cmake-project` при изменении целей и сборки Qt. |
| Обсуждение архитектуры и фиксация решений | `grill-with-docs` по явному вызову. Он сочетает `grilling` и `domain-modeling`. |
| Сложный сбой или регрессия производительности | `diagnosing-bugs`, когда нужно воспроизвести симптом и проверить причину. |
| Разработка через тесты | `tdd`, когда задача требует подхода test-first или запрошены интеграционные тесты. |
| Проектирование или изменение интерфейса модуля | `codebase-design`, когда нужно выбрать границу модуля или определить его контракт. |
| Ревью изменений | `code-review` по запросу на ревью конкретного диффа по стандартам проекта и требованиям задачи. |
| Повторяющаяся проблема или пересмотр практики | [skill-maintenance](../SKILL.md) для проверки применяемых практик и предложений к скиллам, списку и общей библиотеке. |

Ссылки ведут на скиллы из этого репозитория. Остальные имена относятся к установленным скиллам. Если такой скилл недоступен в текущем окружении, примените доступный способ выполнить задачу.
